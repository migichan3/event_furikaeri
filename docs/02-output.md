# 02. 出力 — 何を載せるか

A面/B面の項目定義と、**載せない判断のルール**。

---

## 0. 出力全体の原則

1. **本人が話していないことは書かない。** AIが気を利かせて補完した瞬間、面接で1問掘られて全部崩れる
2. **弱さを消さない。** 「自信度は最低だったが動いた」がこのプロダクトの価値。不安や失敗を綺麗にしない
3. **事実と解釈を分ける。** 解釈を書くときは必ず根拠の事実を併記する
4. **未確認は空欄で残す。** 埋めない。本人に確認を促す
5. **「学びました」「成長しました」で終わる文章を出さない**
6. **順位を先に出さない。** 順位は再現性を伝えない

---

## 1. A面（企業に見せる面 / A4 1ページ）

### 1-1. ヘッダー

| 項目 | 必須 | データ源 | 備考 |
|---|---|---|---|
| 見出し | 必須 | 生成 | **順位ではなく、何をしたかを書く。** 例「崩れた前提から、7時間で作り直した」 |
| 氏名・大学・学部・学年 | 必須 | 本人入力 | |
| イベント名・日付・場所 | 必須 | 本人入力 | 「54時間」と明記する。読み手が制約を理解できる |
| チーム人数・順位 | 任意 | 本人入力 | **右上に小さく。** 主役にしない |

### 1-2. 曲線（自信度の推移）— **主役**

これが言葉より先に伝わる。折れ線の底さえ見れば、何が起きたかの見当がつく。

19時間前に前提が崩れて全員が黙っている瞬間に、「録音されてるから良いこと言おう」と考えられる人間はいません。そんな余裕があるなら、それは谷ではない。

| 要素 | 仕様 |
|---|---|
| 縦軸 | 自信度 10段階（本人の自己申告） |
| 横軸 | 金19:00 〜 日17:00 の時刻 |
| データ点 | 8〜12点。2〜3時間おき |
| 谷の強調 | 最低値の点を色分け + 帯で時間帯を示す |
| 注釈 | 谷に何が起きたかを1〜2行。ゴール地点も明示 |
| 下部の注 | 「自信度が最低だった時間帯に、発言数・移動量が最大」のような**行動との突き合わせ** |

**縦軸を自信度にするかは未確定**（specification.md §9）。不安度、疲労度、あるいは複合指標の可能性がある。

### 1-3. 状況 → 課題 → 行動 → 結果

4カラム。各60〜90字。

- **状況** — 有利な条件ではなく、置かれた立場。「提案者ではなく後から加わった側」のような事実
- **課題** — 時刻と数字で書く。「発表19時間前」「8名中7名に需要なし」「約40分間、全員の手が止まった」
- **行動** — **主語は必ず本人。** 「チームで」を使わない。行動カラムだけ視覚的に強調する
- **結果** — 順位だけでなく、評価の内訳があれば添える

### 1-4. 強み（3つ）

各項目に以下をセットで。1つでも根拠が書けないなら**その強みは載せない**。

| 要素 | 内容 |
|---|---|
| 見出し | 「不安な状態でも、最初の一手を打てる」のように**行動で書く**。「リーダーシップ」のような名詞で書かない |
| 根拠 | インタビューで出た具体的行動を最低2つ。数値があれば入れる |
| 仕事でどう出るか | 1〜2行。**盛らない。** 「どんな環境でも活躍できる」のような無根拠な拡張は禁止 |

**抽出の方針：**
共通点をAIが分類せず、並べて本人に見せる。本人が気づいたものが一番正しい。

### 1-5. 実数（4つ）

| 載せてよい例 | 載せてはいけない例 |
|---|---|
| 顧客への聞き取り人数（総数と本人担当を分ける） | **睡眠時間の短さ**（§3参照） |
| 方針転換から完成までの時間 | 「徹夜した回数」 |
| 方針転換の回数（誰が起案したか併記） | 「作業時間の合計」（長さは能力ではない） |
| 最終資料の本人作成割合 | 根拠を説明できない数字 |

**算出根拠を本人が説明できない数字は載せない。** 聞かれて答えられないと逆効果。

### 1-6. 引用（2つ）

- **本人の言葉** — 弱さを含むもの。「心臓はバクバクしていました」のような。ここが一番効く
- **チームメンバーの言葉** — 匿名の相互評価から。**他者の言葉が1つ入るだけで全体の信頼度が変わる**

### 1-7. 表現の5形式（これ以外は使わない）

A面で使用する視覚的表現形式を限定する。**形式を増やすほど認知負荷が上がる。**

| 形式 | 用途 |
|---|---|
| 折れ線＋帯＋点 | 54時間の全体像（自信度の推移） |
| 横棒の並列 | 止まった3回、続かなかった回数 |
| 文章 | 数字をすべて埋め込む。能力名は使わない |
| 逐語ブロック | 時刻つきでそのまま |
| 2列対比 | 刺さった／刺さらなかった |

**数値カードは使わない。** 単独の数字が浮くと「数字を並べた後に数字のない文を置く」（§5の強弱ルール）が成立しない。

**未確定：**
- 1枚に全5形式は載らない。どれを主役にするかは未決定（Phase 3のテストで決める）
- 「続かなかった回数」を本人に見せると落ち込む可能性がある。表示方法は要検討

## 2. B面（本人用 / 提出しない）

**仮説：学生に刺さるのはこちら。** A面は「作ってもらえて嬉しい」で終わるが、B面は「まだ答えられない」という痛みを伴うので行動が変わる。

### 2-1. ESドラフト

| 種類 | 仕様 |
|---|---|
| 400字版 | ガクチカ想定。字数を表示する |
| 30秒口頭版 | 文章ではなく**①〜⑥の骨子**で出す。丸暗記させない |

いずれも「具体的な行動と、そのときの判断理由」を軸にする。
注記を必ず添える：**そのまま使わず、口に出して読んで直すこと。**

### 2-2. やりがちな失敗（×と○）

このネタ特有の落とし穴を明示する。

× 睡眠時間の短さを実績のように語る
× 「2位でした」を先に言う
× 「チームで協力して」「一丸となって」で始める
× 熱意・気合・やり切った、を根拠として使う
○ 自信が最低だったことを隠さない
○ 自分の案を捨てた話は、聞かれる前に自分から出す

### 2-3. 想定される深掘り（7〜10問）

**答えにくい順**に並べる。各問に「どう答えるか」ではなく**「どこで落ちるか」**を書く。

必ず入れる質問：
1. それ、あなた一人の成果ですか。他のメンバーは何をしていたんですか
2. なぜ最初に発言できたんですか。勇気があった、では答えになりません
3. （自分の案を降ろした場合）単に自信がなかっただけでは
4. 1位ではない。何が足りなかったと思いますか
5. **54時間だから頑張れたのでは。半年、1年続けた経験はありますか**
6. その判断、今でも正しかったと思いますか
7. 弊社の仕事で、同じ場面はどこだと思いますか

**Q5 はこのネタ単体では絶対に返せない。** 短期集中型イベントを題材にする以上、構造的な弱点。弱点として明示するほうが誠実。

### 2-4. まだ埋まっていないところ

消さない。ここを綺麗に埋めると、面接で1問掘られた瞬間に全部崩れる。

- 本人の記憶が曖昧で再確認が必要な箇所（**どの回答が曖昧だったかを記録して自動抽出する**）
- チームメンバーに聞くべきこと（具体的な質問文の形で3つ）
- 探せば出てくる証拠（スライドの版履歴、Slackのログ）
- 数値の算出根拠を説明できるようにしておく項目

## 3. 生成ルール

### 3-1. 判断ルール：同じ事実を、どう変換するか

**実装時に最も重要なルール。** 同じ事実でも、根性の話にするか設計の話にするかで評価が逆に振れる。

| 元の事実 | ✕ このまま載せる | ○ こう変換する |
|---|---|---|
| 3日間で睡眠4時間 | 実数欄に「4時間」 | 「深夜3時40分に『5時に全員一度寝る』と提案し実行。日曜午前の稼働が5名全員維持された」＝撤退線を引ける |
| 徹夜で資料を作った | 「徹夜した」 | 「残り時間から逆算して配分を決めた」 |
| 自分の案が没になった | 触れない | 「自ら取り下げ、理由を説明して合意を取った」＝事実で判断を変えられる |
| 不安で仕方なかった | 隠す | 「自信度10段階中2の状態で最初に発言した」＝不安でも動ける |
| チームで優勝した | 「優勝しました」 | 本人の担当範囲と、他メンバーの貢献を分けて書く |

**原則：「頑張り」は実績にならない。「判断」は実績になる。**

睡眠時間・作業時間・徹夜回数は、実数欄から自動で除外する実装を入れる。

### 3-2. 除外ルール：載せないもの（精査で落とした）

音声データから取得可能だが、**意味が確定しないため載せない**指標。

| 落としたもの | 理由 |
|---|---|
| 笑いが起きた回数87回 | 多いか少ないか判断できない |
| 総発話時間4時間12分 | 3日間なら当たり前。驚きがない |
| 1回あたりの平均発話14秒（単独） | 長短に優劣がない。※「30秒を超えたのは2回だけ」のように文脈と組めば可 |
| 声量・ピッチ・話速（単独） | 意味が確定せず解釈できない。※ピッチ練習の場面なら可 |
| 在席・離席の網掛け | 休憩が可視化されるだけ |
| 話題の変遷タイムライン（単独） | 本人がもう知っている。※引き戻しと組めば可 |
| 強みへの翻訳 | 文章ルールの「能力名を書かない」に反する。行動の記録で止める |

**内部判定には使うが、表には出さない指標：**
- 笑い・声量・発話の重なり → 谷か盛り上がりかの判定に使用
- ピッチ・話速 → トーン変化の検出に使用

### 3-3. 配慮事項：他メンバーの発言の扱い

逐語ブロック（§1-7）や2列対比には他人の発言が入る。録音同意とは別に**掲載の配慮**が必要。

**実装方針：**
- 相手を「Bさん」と匿名化する
- または本人の発言だけ抜き出し、相手は「（応答あり・17秒）」と表示する

**どちらを採用するかは未確定。** Phase 3のテスト時に、本人と相手双方に確認して決める。

## 4. 生成時のバリデーション（実装必須）

生成結果に対して以下を機械的にチェックし、引っかかったら警告を出す。

- [ ] インタビュー回答に根拠のない記述が含まれていないか（**盛り検出**）
- [ ] 「学びました」「成長しました」「貴重な経験」で終わる文がないか
- [ ] 「チームで」「一丸となって」が行動欄に入っていないか
- [ ] 強み3つそれぞれに、根拠となる具体的行動が2つ以上あるか
- [ ] 実数欄に睡眠時間・作業時間が入っていないか
- [ ] 見出しが順位・受賞から始まっていないか
- [ ] 本人の記憶が曖昧だった項目が、断定的に書かれていないか

## 5. 文章作成のガイドライン（推奨）

以下は、観察記録に基づくフィードバック文章を書く際のガイドライン。
AIが生成する文章が「その場にいた人しか書けない」ものになるための指針。

### 最重要原則

これは「AIが自己PRを添削したもの」に見えてはいけない。
その場にいた人しか書けない文章であることが、唯一の価値。
抽象的な能力評価を書いた瞬間に価値がゼロになる。

### 文体

- 「です・ます」で統一する
- 尊敬語・謙譲語は使わない
- 使用禁止：「させていただく」「かと存じます」「〜のほう」「おっしゃる」「お〜になる」
- 事実は過去形で言い切る（「〜していました」「〜ありませんでした」）
- 本人の自己申告を引くときは「事前のシートには〜と書かれていました」のように資料を主語にする
- 最後の一言だけ、敬語を崩してよい（例：「正直うまいと思いました」）

### 内容のルール

- 見出しラベル（「傾聴力：」「主体性：」など）は付けない
- 既製の能力名を書かない（〜力、主体性、柔軟性、論理的思考力 など）
- 数えた結果（回数・時間・「3回とも」「一度もなく」）を必ず入れる
- 実際の発言を引用する
- うまくいかなかった事実も、成功と同じ密度で書く
- 他の参加者との比較・序列は書かない
- 評価や総括で終わらせない。「今後も活きるはずです」のような励ましは書かない
- 「〜という印象を受けました」「〜が見られました」は使わない
- 解釈は断定せず、聞きたいことが実際にあるときだけ問いの形で渡す
- 「かもしれません」は全体で1回まで

### 構成

段落の役割は固定しない。ただし次の原則に従う。

1. 1段落目は場面描写から始める。「〜でした」で場面を置き、2文目で発言か数字を出す。抽象語は1つも使わない
2. 続く段落で、回を重ねた変化を事実で積み上げる
3. 一番重い事実を1つ選び、段落の頭に短文で置く。その直前に「ただ」を入れる
4. 予想を裏切る発見（自己申告と観察のズレなど）があれば転として使う。なければ作らない。捏造は禁止
5. 締めは1〜2行。転があればその言い換え、なければ観察者としての一言

### 接続詞

- 段落の頭には接続詞を置く（ただ、むしろ、一方で、しかも など）
- 段落内では、逆のことを言うときだけ入れる。時間順に進む箇所には不要
- 使用禁止：「しかしながら」「したがって」「加えて」「また」
- 「また」を使いたくなったら、文の順番が悪い。並べ替える

### 強弱

- 文の長さを揃えない。短文で切ると音量が上がる
- 数字を並べたあとに、数字のない文を置く
- 一番重い事実は1行で置き、説明を足さない

### 箇条書きを使う場合

- 見出しラベルは付けない。文だけを並べる
- 1項目1〜2行。2行目に数字か実際の発言を置く
- 1ブロック3項目まで
- 項目の長さを揃えない
- 形容詞で終わる行を作らない

### 出力前の自己チェック

次に1つでも当てはまったら書き直す。

- 能力名を使っている
- 数字が1つも入っていない
- 実際の発言の引用がない
- 失敗・うまくいかなかった事実が書かれていない
- 励ましや総括で終わっている
- 全部の文がだいたい同じ長さになっている
- この文章が、観察していなくても書けてしまう

### 参照例

```
2日目の午後でした。残り7分の時点で3人が別々の話をしていて、
このままだとまとまらないなと見ていました。
そこで「決めるのは予算の上限だけですよね」と言われて、議論が1つに戻りました。

同じ動きは初日からありました。話を振った回数は2回、4回、3回で、
うち半分くらいはそこから論点が動いています。
しかも残り時間が短くなっても、この動きは減りませんでした。
発言量そのものは半分近く落ちるのに、振るのだけはやめない。

ただ、結論を出すところは毎回人に譲っていました。
進行と整理は自分から取りに行くのに、決めるところだけは渡していました。

これは意識してやっていましたか。

あの一言は、正直うまいと思いました。
```
