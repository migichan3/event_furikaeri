## このプロジェクト固有の適用

### 出力形態
- **HTML 1枚 × 2面（A4印刷前提）**
- ブラウザの印刷機能経由でPDF化
- 画面表示と印刷出力の両方で破綻しないこと

### タイポグラフィ
| 項目 | 値 | 理由 |
|---|---|---|
| フォント | Noto Sans JP | 日本語の視認性。Inter等の欧文フォントを日本語に当てない |
| 本文サイズ | 16px | 印刷時の可読性を担保 |
| 行間（本文） | 1.7 | 日本語の密度に対応 |
| 行間（見出し） | 1.2〜1.3 | |
| フォント読み込み | Google Fonts `display=swap` + サブセット | 重い日本語フォントの最適化 |

### 色彩
| 項目 | 値 | 理由 |
|---|---|---|
| テキスト | #1a1a1a〜#333 | 純黒 #000 は避ける（印刷時の濃淡、画面での柔らかさ） |
| 背景 | #fafaf8 or #f7f6f3 | オフホワイト（真っ白より温かみ） |
| メインカラー | ネイビー系 #1e3a5f | 信頼感、くすみカラー |
| アクセント | えんじ、深緑など | 彩度を抑えた日本の伝統色 |
| **禁止** | 紫→ピンクのグラデーション | AIスロップの典型、日本のユーザーに軽薄・不信の印象 |

### コンポーネントの造形
| 項目 | 値 |
|---|---|
| 角丸 | 4〜6px（繊細な値） |
| 階層表現 | 1px淡いボーダー（#e5e5e5） |
| シャドウ | 0 1px 3px rgba(0,0,0,0.06) 程度、控えめに |

### 曲線グラフ（主役コンポーネント）
- **線の色：** 彩度を抑えたネイビー系またはえんじ
- **谷の強調：** 色分け + 薄い帯（rgba）
- **データ点：** 4〜6pxの円、ホバー時は拡大（印刷版では不要）
- **軸ラベル：** 14px、#666
- **グリッド線：** 1px、#e5e5e5、控えめに

### レイアウト構成

#### A面（1ページ目）
```
┌─────────────────────────────────┐
│ ヘッダー（見出し、基本情報）      │ 上部 80px
├─────────────────────────────────┤
│ 曲線グラフ（主役）               │ 中央 350px
│ ・自信度の推移                   │
│ ・谷の強調                       │
├─────────────────────────────────┤
│ STAR（状況→課題→行動→結果）     │ 4カラム
├─────────────────────────────────┤
│ 強み3つ（根拠付き）              │ 3カラム
├─────────────────────────────────┤
│ 実数4つ + 引用2つ                │ 下部
└─────────────────────────────────┘
```

#### B面（2ページ目）
```
┌─────────────────────────────────┐
│ ESドラフト（400字版・30秒版）    │
├─────────────────────────────────┤
│ やりがちな失敗（×と○）          │
├─────────────────────────────────┤

```

### 余白・マージン
- **8ptグリッド基準**（4, 8, 12, 16, 24, 32, 48, 64px）
- セクション間：32〜48px
- カード内の余白：16〜24px
- 行間余白：8〜12px

## 印刷時の制約と対策

### A4サイズ（210mm × 297mm）
- **印刷可能領域：** 上下左右各15mm程度のマージンを考慮
- **1ページあたりの高さ制限：** 約1100px（ブラウザによって誤差あり）
- **改ページ制御：** `page-break-inside: avoid` をセクションに適用

### CLS対策（印刷時のレイアウトシフト防止）
- グラフ・画像に `width` `height` を明示
- フォント読み込み：`font-display: swap` + サイズ調整
- 非同期要素を排除（印刷時は全て同期描画）

### カラー vs モノクロ
- モノクロ印刷でも情報が失われないこと
- 曲線の谷：色だけでなく帯＋ラベルで強調
- 強みの根拠：箇条書きマーカーで視認性確保

### 印刷用CSS
```css
@media print {
  @page {
    size: A4;
    margin: 15mm;
  }

  /* セクションの改ページ防止 */
  section {
    page-break-inside: avoid;
  }

  /* A面とB面の改ページ */
  .page-a {
    page-break-after: always;
  }

  /* 不要な要素を非表示 */
  .no-print {
    display: none;
  }
}
```

## 編集機能のUI（Phase 3）

Phase 3で実装する編集機能の操作ルール。

### インタラクション
- **編集モード切替：** 右上に「編集」ボタン（44×44px以上のタップ領域）
- **保存・キャンセル：** 明示的な確認ダイアログ（不可逆な操作の前）
- **リアルタイムプレビュー：** 編集中も印刷イメージを横に表示

### フォーム設計（「慮り」のある設計）
- 入力例を提示：「例：金19:00」
- 必須/任意を明示：赤アスタリスクではなく「必須」ラベル
- バリデーション：blur時に実施（入力中に赤く責めない）
- エラーメッセージ：ユーザーを責めず、次の行動を導く
  - NG：「無効な入力です」
  - OK：「時刻の形式をご確認ください（例：19:00）」

### 状態表示
- 保存中：ローディングスピナー + 「保存中...」
- 保存完了：緑のチェックマーク + 「保存しました」（2秒後に消える）
- エラー：赤の警告アイコン + 具体的なエラー内容 + 再試行ボタン

## AIスロップ回避チェック

実装後、以下に該当していないか必ず確認する。該当したら修正。

- [ ] Interや system-ui だけで日本語を表示していないか
- [ ] line-height が1.5以下になっていないか
- [ ] 紫〜ピンクのグラデーション、意味のないぼかし玉（blob）を置いていないか
- [ ] 角丸16px超・大ぶりシャドウの「ふわふわカード」を量産していないか
- [ ] 全セクションが同じ高さ・同じ余白の「3列カード反復」になっていないか
- [ ] 「〜を実現します」「〜ではないでしょうか」等のAI特有言い回しが残っていないか

**シルエットテスト：** 画面を200px幅・白黒・ブロックのみに縮小して、他の振り返りツールと見分けがつくか確認する。

## Phase 1完了時の確認事項

Phase 1（骨格）完了時にスクリーンショットを撮り、以下を確認する：

1. **`skills/migiee-ui-ux-check/SKILL.md` でレビュー**
   - 数値基準（16px、行間1.7、角丸4〜6px等）を満たしているか
   - 日本語フォント・色彩が適用されているか
   - AIスロップの典型パターンに該当していないか

2. **印刷プレビュー確認**
   - A4サイズに収まっているか
   - 改ページ位置は適切か
   - モノクロ印刷でも情報が読めるか

3. **アクセシビリティ**
   - コントラスト比：通常テキスト4.5:1以上
   - タップ領域：44×44px以上（編集ボタン等）
   - キーボードフォーカスリングが消されていないか

Phase 1でこれらを確認せずにPhase 2へ進まない。
