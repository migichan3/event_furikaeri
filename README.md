# event_furikaeri

Startup Weekend参加学生の54時間を就活で語れる形に変換するツール。

## 概要

行動力も成果もあるのに面接で伝えられない学生向け。
音声記録から沈黙・笑い・トーン・発話量・内容を解析して、
「いつ・何を・どう判断したか」を可視化する。

## 現在の状態

Phase 0（仕様確定中）。コードはまだなし。

確定：
- 入力は音声のみ（既存のボイスレコーダー/スマホ）
- カメラ・センサー類は使わない
- 沈黙検出（谷の特定）は必ず取れる設計

未確定：
- マイク配置
- 解析の自作 or Hylable使用
- 話者分離の実現性

## 原則

- 盛らない（本人が話してないことは書かない）
- 弱さを消さない（不安や失敗も記録）
- 事実と解釈を分ける
- 未確認は未確認と明記
