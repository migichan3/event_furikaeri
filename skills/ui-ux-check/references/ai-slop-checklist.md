# AIスロップ（AIっぽさ）チェックリスト

AI生成UIは「方向性の決定がない」ときに統計的に最も安全な平均値へ収束する。これがAIスロップの根本原因。レイヤーごとに機械的にチェックする。

## 収束しがちな3つの型（まず引っかかっていないか確認）

1. クリーム色背景（#F4F1EA近辺）＋高コントラストのセリフ見出し＋テラコッタ系アクセント（#D97757近辺）
2. ほぼ黒背景＋アシッドグリーンかバーミリオンの単色差し
3. ヘアライン罫線＋角丸ゼロの新聞風レイアウト

ブリーフ（要件）がこれらを明示的に指定しているなら問題ない。要件が自由な軸でこれらに落ち着いているなら要指摘。

## 視覚レイヤー

| テル | チェック観点 | 直し方の指摘 |
|---|---|---|
| 紫→青グラデーション | 使われていないか | 単色＋トーン差（5%以内）に置換、または削除 |
| 全カード共通のグレー1px枠線 | 区切りの手段が枠線一択になっていないか | 余白 → 背景明度3〜5%差 → ソフトなエレベーション、の順に検討し、伝わった時点で止める |
| Inter/Robotoの見出し | 見出しがデフォルト書体のままか | 見出しだけ別ファミリーに変更（和文サイトなら和文見出し書体） |
| 3列カードの反復 | 同じ構造のセクションが連続していないか | 列数を変える、幅を非対称にする、1枚だけ強調する |
| 意味のない装飾ライン | アクセントカラーの縦線・横線・グラデラインが情報と無関係に置かれていないか | 階層や区切りを表す時のみ残し、他は削除 |
| 要求されていないダークモード | 要件にないのに実装されていないか | 要件通りに戻す |
| 絵文字アイコン・英語小ラベル | 🚀✨等の絵文字アイコンや、日本語サイトでの英語ラベル多用がないか | アイコンセットで統一、日本語サイトは日本語ラベルに |

## 構造レイヤー（気づかれにくいが致命的）

- **緩急の欠如**：セクションの高さ・余白・揃え（左/中央）が全て均一になっていないか。人間が作るページは大→小、テキスト中心→画像中心、左揃え→中央揃え、と変化がある
- **中央揃えの多用**：左揃えの塊が1つもないと機械的に見える
- **垂直パディングが全セクション同じ**（例：全部80px）
- **テンプレ的ヒーロー**：「大きい数字＋小さいラベル＋補助スタッツ＋グラデアクセント」が本当に最適な選択として使われているか、それとも安全策として選ばれていないか
- **意味のない01/02/03ナンバリング**：実際に時系列・工程順を表しているか。単なる箇条書きへの連番付けになっていないか
- **フェイクUI・ダミーデータ**：ダミー数値、ランダムなグラフ、ただの円のユーザーアイコンが残っていないか。実データがなければそのセクション自体を削るべきと指摘

**シルエットテスト**：スクリーンショットを200px幅・白黒・ブロックのみ（テキストは線、アバターは円）に縮小し、同業界の競合5サイトと並べる。自分のものがどれか判別できなければ構造的にスロップ。可能ならこのテストの実施を提案する。

## モーションレイヤー

- 全要素に同じフェードインスクロールアニメーションがかかっていないか
- hoverで全カードが同じように浮く、という一律処理になっていないか
- ヒーローに意味のない動くグラデーション背景・パーティクルがないか
- 「大胆さは1箇所に集中」できているか。散らばったエフェクトより1つのオーケストレーションされた見せ場の方が強い

## コピーレイヤー（日本語）

以下のパターンが本文コピーに残っていないか確認する。

- 「〜を実現します」「〜に迫っていきましょう」「〜ではないでしょうか」等、教科書の序文のような言い回し
- 「第一に」「第二に」「最後に」と小論文のように整理されすぎた構造
- 日本語の日常で使わない翻訳調の比喩（「パズルのピースのようなもの」「銀の弾丸はありません」）
- 「革新的な」「シームレスな」「次世代の」など中身のない形容詞の多用
- ボタンラベルが「送信する」「詳細はこちら」のような一般語になっている（具体的な動詞・目的語にすべき：「無料で見積もりを取る」等）
- 全文に対して「この文はどの会社にも当てはまるか？」を問い、当てはまるものは固有名詞・数字・実際の顧客の言葉に書き換えるべきと指摘

## 実装レイヤー

- shadcn/uiのデフォルトそのまま（グレーカード＋Tailwindのblue-600ボタン）になっていないか
- `border-radius`が全箇所`rounded-lg`など単一値になっていないか（意図的統一なら問題ないが、思考停止かは要確認）
- 影が`shadow-md`一律になっていないか
- 画像が全てストック写真の同系統になっていないか（実際のブランド写真への置き換えを提案）
- コンポーネントの状態がdefault/hoverしかなく、focus/disabled/loading/error/emptyが未定義でないか
- `h1`が複数存在する、または見出しが全部`div`になっていないか（構造的な手抜きの兆候）

## 指摘時の書き方

AIスロップ指摘は「なぜAIっぽく見えるか」の理由（上記のどのテルに該当するか）とセットで書く。単に「AIっぽい」とだけ言わない。

```
### 🟡 Medium（AIスロップ）
- [構造] ヒーロー下に3列カードが3セクション連続、幅・高さ・余白が全て同一
  → 2セット目は画像主体のブロックに変える、または列数・幅を変えて緩急をつける
```
