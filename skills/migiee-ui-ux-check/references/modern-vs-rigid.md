# モダンデザインの原則と「硬すぎ」問題

出典: DEAP「【2025年最新】現代を彩るモダンデザインの魅力とは？」（https://deap.co.jp/column/c25134/）を参考に、AIスロップ・硬さの問題と接続して整理したもの。

「Claudeっぽい」「AIっぽい」「硬い」と感じるサイトは、しばしば**モダンデザインの実践を間違えて、装飾ゼロのミニマルデザインに寄りすぎている**ことが原因。この2つは似て非なるもの。

## モダン ≠ ミニマル（最重要の区別）

| | ミニマル | モダン |
|---|---|---|
| 姿勢 | 装飾を徹底的に排除する | 機能美と洗練を両立させる |
| 柔軟性 | 低い（削ることが目的化しやすい） | 高い（ブランド文脈を反映する） |
| 色 | 極力使わない | モノトーン＋意図を持った1〜2色のアクセント |
| リスク | 「情報が足りない」「冷たい」「AIっぽい」に転びやすい | ブランドの個性が乗る |

**装飾を削りきった結果が「Claude的な硬さ」**。モダンデザインの本来の定義は「装飾を排除すること」ではなく、「機能美と洗練を両立しながら、ブランドの意図を正確に伝えること」。ここを混同すると、意図せずAIスロップの型3（ヘアライン罫線＋角丸ゼロの新聞風レイアウト）に落ちる。

## 硬く見える時にまず疑う4つのポイント

1. **無彩色＋グレーだけで、ブランドに紐づいたアクセントカラーがない**
   → Apple・無印良品・資生堂・Netflix・メルカリはいずれもモノトーン＋1〜2色だが、その色は事業やブランドの文脈から選ばれている（資生堂＝白黒赤、Netflix＝黒赤）。汎用パープル/ブルーグラデーションではない。**自社の何色か**を1つ決める
2. **角丸・形状に緩急がなく、全て0か全て同じ値**
   → 全部シャープ、または全部同じ半径だと機械的に見える。1箇所だけ有機的な丸み・非対称な形を入れると温度感が出る
3. **柔らかい装飾要素がゼロで、直線とグリッドのみで構成されている**
   → グラデーション・ぼかし（blur）・重なりのある柔らかい図形は「装飾」だが、AIスロップの紫グラデ多用とは違う。**ブランドカラー内でのトーン差（5〜15%程度）**に絞れば、装飾過多にもならず硬すぎもしない
4. **モーションが皆無で静止画のように見える**
   → 全く動かないUIは「安全だが無機質」に見えやすい。ヒーローや主要CTA周りにだけ、ごく控えめな動き（150〜300msのトランジション、微細なパララックスやフェード）を1箇所集中投下する

## 「引き算」と「思考停止」の違い

記事内の失敗例がそのまま診断基準になる：
- 余白の取り方が雑でコンテンツが間延びして見える → 単なる余白過多ではなく、意図した余白か
- フォント選定に統一性がなくチグハグ → 見出し・本文・ボタンで使うフォントは絞られているか
- **装飾を排除しすぎて、どこがボタンか判別できない** → これが「モダンの失敗」の代表例。ボタンには最低限、色/影/枠のいずれかで「押せる」ことが視覚的に伝わっているか

「硬い」の正体は多くの場合、この3つ目——**引き算しすぎて機能性まで失っている状態**。モダンの本質は引き算ではなく、「何を残すかの意図」にある。

## 業種・ブランド文脈による適用バランス

| タイプ | 適用の目安 | 理由 |
|---|---|---|
| BtoB（SaaS・コンサル・医療） | 高機能性・信頼性重視で完全モダン寄りでよい | 信頼と専門性を視覚的に伝える必要がある |
| BtoC（エンタメ・地域密着・個人ブランド・toC消費財） | 装飾の調整が必要。温かみ・感情訴求の要素を戻す | 無機質なモダンは逆効果になりうる |

対象サイトがどちらの文脈かで、「どこまで硬くしてよいか」の答えは変わる。個人のポートフォリオ/プロダクトLPなど親しみを出したい文脈なら、意図的にBtoC側のバランスに寄せてよい。

## 色彩心理（配色選定の参考）

| 色 | 感情・印象 | 使用例 |
|---|---|---|
| 白 | 清潔感、余白、信頼 | 医療系サイト、化粧品ブランド |
| 黒 | 高級感、力強さ | ファッション、テック系 |
| 青 | 安定性、誠実さ | BtoB、金融業界 |
| 赤 | 行動喚起、情熱 | キャンペーンLP、CTAボタン |
| グレー | バランス、中立性 | 背景、UIパーツ |

日本市場特有の文化的含意（`japan-specific.md`）とは別レイヤーの、より一般的なマーケティング色彩心理。両方を踏まえて選定する。

## フォント選定の一貫性

- 本文・見出し・ボタンで異なるフォントを使いすぎない（2〜3ロール以内）
- ブランドの印象に合わせてフォントの性格を選ぶ：信頼性重視ならNoto Sans/Helvetica系、親しみやすさ重視ならRounded Gothic/Quicksand系の丸みのある書体
- OS・ブラウザによる表示崩れ（フォールバック）への配慮

## 情報階層（ヒエラルキー）の明確化

- 見出し（H1〜H3）と本文のサイズ差が明確か
- 色や太さのバリエーションで重要度が可視化されているか
- 「概要→強み→事例→CTA」のような自然な情報構成になっているか（特にサービス紹介ページ）

## レビュー時の具体的な指摘の書き方

```
### 🟡 Medium（モダン⇔硬さのバランス）
- [色] アクセントカラーがグレースケールのみで、ブランド文脈に紐づいた色がない
  → ブランドカラーから1色を選び、CTAボタンとアクセント要素に使う
- [形状] 角丸が全要素で0、またはrounded-lgで統一され緩急がない
  → ヒーロー画像やカード1種類だけ大きめの角丸/有機的な形にし、他は現状維持で緩急をつける
- [装飾] 柔らかい装飾要素（グラデーション、ぼかし）が皆無で直線グリッドのみ
  → ブランドカラー内トーン差5〜15%のグラデーションをヒーロー背景に1箇所だけ導入
- [モーション] トランジション・アニメーションが一切ない
  → 主要CTAのhoverと、ヒーローの初回表示にのみ150〜300msのフェード/トランジションを追加
```
